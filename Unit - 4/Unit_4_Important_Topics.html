1Graph basics: degree, handshaking lemma and representations  ★★

In one minute
What it solves

Counts edges from degrees, checks whether a degree list is possible, and stores a graph for algorithms.

The concept

The degree of a vertex is its number of edges. Each edge adds 2 to the total degree, so the sum of degrees is twice the number of edges and the number of odd-degree vertices is always even.

Where it is used

Networks (social, road, computer); the input format for every graph algorithm.

Handshaking
Σv deg(v) = 2|E|
Handshaking lemma.
Representations
Adjacency matrix: n × n, 1 if an edge (space n2);   adjacency list: neighbours of each vertex (space n + m)
List for sparse graphs, matrix for dense graphs or quick edge checks.
Worked example — edges from degrees
A graph has degrees 3, 3, 2, 2, 2. How many edges? Is a graph with degrees 3, 3, 3 possible?
  1. Sum of degrees3 + 3 + 2 + 2 + 2 = 12
  2. Edges12 / 2 = 6
  3. Second list3 + 3 + 3 = 9 is odd → impossible
6 edges; degrees 3, 3, 3 cannot exist.
Practice
  1. Find: the number of edges.10 vertices, each of degree 3.
    Sum 30, so 15 edges.
  2. Answer: matrix or list?A road map with 10 000 junctions, each joined to about 4 others.
    Adjacency list: the graph is sparse, and a matrix would waste 108 cells.

2Graph types: complete, bipartite, trees, Euler and Hamilton  ★★

In one minute
What it solves

Recognises special graphs and answers “can I travel every road (or visit every place) exactly once?”

The concept

Kn: every pair joined. Bipartite: two sides, edges only across (no odd cycle). Tree: connected, no cycles. Euler circuit uses every edge once (all degrees even); Hamiltonian cycle visits every vertex once (no simple test).

Where it is used

Route planning (Euler: postman routes; Hamilton: travelling salesman), matching problems.

Edge counts
|E(Kn)| = n(n − 1)2,   |E(Km,n)| = mn,   tree: |E| = n − 1
Euler's test
Euler circuit ⇔ connected and every degree even;   Euler path ⇔ exactly 0 or 2 odd-degree vertices
Start and end the path at the two odd vertices.
Worked example — edge counts and an Euler path
Edges: A–B, A–C, A–D, B–C, C–D, D–E, C–E. Also find |E| for K6 and K3,4.
  1. DegreesA 3, B 2, C 4, D 3, E 2
  2. Odd-degree verticesA and D (exactly two) → Euler path from A to D, but no Euler circuit
  3. K66 × 5 / 2 = 15 edges
  4. K3,43 × 4 = 12 edges
Euler path (A → D) exists, no circuit; K6 has 15 edges, K3,4 has 12.
Common trap
Euler is about edges, Hamilton is about vertices. Do not mix them up.
Practice
  1. Find: the edges.How many edges do K5 and K2,3 have?
    K5: 10; K2,3: 6.
  2. Answer: Euler circuit? Give the reason.A connected graph where every vertex has degree 4.
    Yes: all degrees are even.

3Graph traversal: BFS, DFS and topological sort  ★★★

In one minute
What it solves

Visits every vertex systematically: level by level (BFS) or as deep as possible first (DFS); orders tasks with dependencies (topological sort).

The concept

BFS uses a queue and finds shortest paths in unweighted graphs. DFS uses a stack (or recursion). A topological sort lists a DAG's vertices so every edge points forward.

Where it is used

Shortest hops in networks, web crawling, maze solving, build and course-prerequisite ordering.

Cost
BFS and DFS: time O(V + E) with adjacency lists
Each vertex and each edge is handled once.
Topological sort
Topological order exists ⇔ the directed graph has no cycle (DAG)
Kahn's method: repeatedly remove a vertex with in-degree 0.
Worked example — BFS, DFS and a topological order
Directed edges 1→2, 1→3, 2→4, 2→5, 3→6, 5→6. Traverse from 1, taking smaller neighbours first (ignore direction for BFS/DFS).
  1. BFS (queue)1 | 2, 3 | 4, 5, 6 → 1, 2, 3, 4, 5, 6
  2. DFS (go deep)1 → 2 → 4, back, 5 → 6, back to 1, then 3 → 1, 2, 4, 5, 6, 3
  3. Topological (Kahn)in-degree 0: 1 → then 2, 3 → then 4, 5 → then 6 → 1, 2, 3, 4, 5, 6
  4. Checkevery edge goes from earlier to later in the order ✓
BFS 1,2,3,4,5,6; DFS 1,2,4,5,6,3; a valid topological order 1,2,3,4,5,6.
Practice
  1. Answer: which data structure?BFS and DFS each use which data structure?
    BFS: a queue; DFS: a stack (or recursion).
  2. Answer: possible? Give the reason.Can a graph with the cycle A → B → C → A be topologically sorted?
    No: a topological order exists only for graphs without cycles.

4Shortest paths: Dijkstra's algorithm  ★★★

In one minute
What it solves

Finds the shortest distance from one source to every vertex in a graph with non-negative weights.

The concept

Keep a tentative distance for every vertex. Repeatedly settle the unsettled vertex with the smallest distance and relax its edges: if going through it is shorter, update the neighbour.

Where it is used

GPS navigation, network routing, game path-finding.

Relaxation
relax: d[v] ← min(d[v], d[u] + w(u, v))
With a priority queue: O((V + E) log V). Negative weights need Bellman–Ford instead.
How to solve it in the exam
  1. Set d[source] = 0 and every other d = ∞.
  2. Pick the unsettled vertex u with the smallest d and settle it.
  3. Relax every edge u–v.
  4. Repeat until all vertices are settled. Keep a table of the d values at each step.
Worked example — from A
Undirected weighted graph: A–B 4, A–C 2, B–C 1, B–D 5, C–D 8, C–E 10, D–E 2.
  1. Settle A (0)C = 2, B = 4
  2. Settle C (2)B = min(4, 2 + 1) = 3, D = 2 + 8 = 10, E = 2 + 10 = 12
  3. Settle B (3)D = min(10, 3 + 5) = 8
  4. Settle D (8)E = min(12, 8 + 2) = 10
  5. Settle E (10)done
Distances from A: B 3, C 2, D 8, E 10 (path to E: A–C–B–D–E).
Common trap
The direct edge is not always shortest: A–B costs 4, but A–C–B costs only 3.
Practice
  1. Answer: why does it fail?Why can Dijkstra give wrong answers with negative edge weights?
    A settled vertex is assumed final; a later negative edge could still make it cheaper. Use Bellman–Ford.
  2. Find: the shortest path.In the example graph, what is the shortest path from A to D?
    A–C–B–D with length 8.

5Minimum spanning tree: Kruskal and Prim  ★★★

In one minute
What it solves

Connects all vertices with the cheapest possible set of edges and no cycles.

The concept

Kruskal: sort all edges by weight and add each one unless it makes a cycle. Prim: grow one tree from a start vertex, always adding the cheapest edge leaving the tree. Both give n − 1 edges.

Where it is used

Designing cheapest cable, pipe or road networks; clustering.

Facts
Kruskal: O(E log E);   Prim with a heap: O(E log V);   MST has n − 1 edges
Worked example — Kruskal on the same graph
Undirected weighted graph: A–B 4, A–C 2, B–C 1, B–D 5, C–D 8, C–E 10, D–E 2.
  1. Sort edgesB–C 1, A–C 2, D–E 2, A–B 4, B–D 5, C–D 8, C–E 10
  2. Take B–C (1), A–C (2), D–E (2)no cycles yet
  3. A–B (4)A and B are already connected through C → skip (cycle)
  4. B–D (5)joins {A, B, C} with {D, E} → take; now 4 edges = n − 1, stop
MST: B–C, A–C, D–E, B–D, total weight 10.
Practice
  1. Find: the number of edges.A connected graph has 8 vertices. How many edges are in its MST?
    7 (n − 1).
  2. Answer: Kruskal or Prim?Which one sorts all edges first, and which grows a tree from one vertex?
    Kruskal sorts all edges; Prim grows from a start vertex.

6Graph colouring and the chromatic number  ★★

In one minute
What it solves

Assigns colours so that joined vertices differ, using as few colours as possible.

The concept

The chromatic number χ(G) is the fewest colours needed. Welsh–Powell is a greedy method: sort vertices by degree and give each colour to as many non-adjacent vertices as possible.

Where it is used

Exam timetabling, register allocation in compilers, frequency assignment, map colouring.

Facts and bound
χ(Kn) = n;   χ(even cycle) = 2, χ(odd cycle) = 3;   χ(G) ≤ Δ(G) + 1
Δ is the largest degree. A triangle in the graph means at least 3 colours.
How to solve it in the exam
  1. List the vertices in decreasing order of degree.
  2. Give colour 1 to the first vertex, then to every later vertex not adjacent to any vertex with colour 1.
  3. Repeat with colour 2 for the uncoloured vertices, and so on.
  4. Count the colours used.
Worked example — Welsh–Powell
Edges: A–B, A–C, A–D, B–C, C–D, D–E, C–E. Degrees: C 4, A 3, D 3, B 2, E 2.
  1. OrderC, A, D, B, E
  2. Colour 1C (every other vertex touches C) → {C}
  3. Colour 2A, then E (not adjacent to A) → {A, E}
  4. Colour 3D, then B → {D, B}
  5. Lower boundA–B–C is a triangle, so at least 3 colours are needed
χ = 3: {C}, {A, E}, {B, D}.
Practice
  1. Find: the chromatic number.χ(K5) and χ(C6)?
    K5: 5; C6 (even cycle): 2.
  2. Answer: what do colours stand for?In exam timetabling, what are the vertices, edges and colours?
    Vertices = exams, edge = a student takes both, colours = time slots.

7Max-flow min-cut: Ford–Fulkerson  ★★★

In one minute
What it solves

Finds the most that can flow from a source s to a sink t through a network with capacities.

The concept

Repeatedly find an augmenting path from s to t in the residual graph and push the bottleneck amount. Stop when no path is left. The max flow equals the capacity of the smallest cut separating s from t.

Where it is used

Traffic and pipeline capacity, bipartite matching (job assignment), network reliability.

Max-flow min-cut theorem
max flow value = min { capacity of a cut (S, T) : s ∈ S, t ∈ T }
A cut's capacity adds only the edges going from S to T.
Augmenting
push = bottleneck = min residual capacity on the path; residual: forward c − f, backward f
Edmonds–Karp picks the shortest path (BFS): O(V E2).
Worked example — a small network
Capacities s→a 3, s→b 2, a→b 1, a→t 2, b→t 3.
  1. Path s→a→tbottleneck min(3, 2) = 2 → flow 2
  2. Path s→b→tbottleneck min(2, 3) = 2 → flow 4
  3. Path s→a→b→tresiduals 1, 1, 1 → push 1 → flow 5
  4. No more pathsboth edges out of s are full
  5. Check with a cutS = {s}: capacity 3 + 2 = 5 = flow ✓
Maximum flow = 5 = minimum cut.
Common trap
When adding up a cut's capacity, count only the edges from the s-side to the t-side, not the backward ones.
Practice
  1. Answer: state the theorem.What does the max-flow min-cut theorem say?
    The maximum flow equals the capacity of the minimum cut.
  2. Find: the cut capacity.In the example, the cut S = {s, a}, T = {b, t}.
    Edges s→b 2, a→b 1, a→t 2 → 5.
