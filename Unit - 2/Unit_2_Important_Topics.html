1Vectors: dot product, norm, angle, projection and cross product  ★★★

In one minute
What it solves

Measures length, distance and the angle between two vectors, and finds a vector perpendicular to two others.

The concept

The dot product multiplies matching parts and adds them; it is 0 when vectors are at right angles. The norm is the length. The cross product (3-D only) gives a vector perpendicular to both.

Where it is used

Cosine similarity, distances between data points (k-NN, clustering), normals in graphics.

Dot product and norm
a·b = a1b1 + a2b2 + … = |a| |b| cos θ;   |a| = √a·a
Dot product → angle; 0 means perpendicular (orthogonal).
Projection
projba = a·b|b|2 b
The shadow of a on b.
Cross product
a × b = (a2b3 − a3b2,  a3b1 − a1b3,  a1b2 − a2b1)
|a × b| = area of the parallelogram on a and b.
Worked example — angle, projection, distance and a cross product
a = (3, 4), b = (4, 3); and u = (1, 2, 3), v = (4, 5, 6).
  1. Dot producta·b = 12 + 12 = 24;  |a| = |b| = 5
  2. Anglecos θ = 24/25 = 0.96 → θ ≈ 16.26°
  3. Projection of a on b(24/25)(4, 3) = (3.84, 2.88)
  4. Distance|a − b| = √1 + 1 ≈ 1.414
  5. Cross productu × v = (2·6 − 3·5, 3·4 − 1·6, 1·5 − 2·4) = (−3, 6, −3); area = √54 ≈ 7.35
θ ≈ 16.26°, projection (3.84, 2.88), distance 1.414, u × v = (−3, 6, −3).
Common trap
The dot product gives a number; the cross product gives a vector. Watch the middle sign of the cross product.
Practice
  1. Find: the norm and unit vector.a = (1, 2, 2).
    |a| = √1 + 4 + 4 = 3; unit vector = (1/3, 2/3, 2/3).
  2. Answer: orthogonal? Give the reason.a = (1, 2), b = (2, −1).
    a·b = 2 − 2 = 0, so yes.

2Determinant, inverse and rank  ★★★

In one minute
What it solves

Tells whether a matrix can be inverted (and a system has one solution), and finds the inverse.

The concept

The determinant is a single number from a square matrix; if it is 0 the matrix is singular (no inverse). Rank is the number of independent rows or columns.

Where it is used

Solving linear systems, checking independence of features, transformations in graphics.

2 × 2
det [a b; c d] = ad − bc,    A−1 = 1ad − bc [d −b; −c a]
Swap the diagonal, change the signs of the other two, divide by the determinant.
3 × 3
det A = a11(a22a33 − a23a32) − a12(…) + a13(…)
Expand along the first row with signs + − +.
Rank
rank = number of non-zero rows after row reduction;   rank + nullity = number of columns
Worked example — a 2 × 2 inverse and a 3 × 3 determinant
A = [4 7; 2 6].   B = [2 0 1; 1 3 2; 1 1 1].
  1. det A4 × 6 − 7 × 2 = 24 − 14 = 10
  2. A−1(1/10) [6 −7; −2 4] = [0.6 −0.7; −0.2 0.4]
  3. det B, first row2(3·1 − 2·1) − 0(…) + 1(1·1 − 3·1) = 2(1) + 1(−2) = 0
  4. What it meansB is singular: no inverse; its rank is 2 (rows are dependent)
det A = 10 and A−1 = (1/10)[6 −7; −2 4]; det B = 0, so B has no inverse (rank 2).
Common trap
Check AA−1 = I. A common slip is forgetting to change the signs of b and c.
Practice
  1. Find: det and inverse.A = [3 2; 1 4].
    det = 12 − 2 = 10; A−1 = (1/10)[4 −2; −1 3].
  2. Find: the rank.A = [1 2; 2 4].
    Row 2 = 2 × row 1, so rank 1 and det = 0: no inverse.

3Solving linear systems by Gaussian elimination  ★★

In one minute
What it solves

Solves several linear equations at once, and shows whether there is one, none or infinitely many solutions.

The concept

Write the augmented matrix, use row operations to make zeros below the diagonal (row-echelon form), then back-substitute from the last equation upwards.

Where it is used

Circuit analysis, fitting models, any “n equations, n unknowns” problem.

Method
[A | b]  →  row operations  →  [U | c], then solve from the bottom row up
Allowed: swap rows, multiply a row by a non-zero number, add a multiple of one row to another.
How many solutions
unique solution: rank A = rank [A|b] = n;   none: rank A < rank [A|b];   infinite: rank A = rank [A|b] < n
Worked example — three equations
x + y + z = 6,   2x + 3y + z = 11,   x − y + 2z = 5.
  1. R2 ← R2 − 2R1y − z = −1
  2. R3 ← R3 − R1−2y + z = −1
  3. R3 ← R3 + 2R2−z = −3 → z = 3
  4. Back-substitutey − 3 = −1 → y = 2;  x + 2 + 3 = 6 → x = 1
x = 1, y = 2, z = 3 (check: 2 + 6 + 3 = 11 ✓).
Practice
  1. Find: x and y.x + y = 5, 2x − y = 1.
    Add them: 3x = 6, so x = 2, y = 3.
  2. Answer: what does it mean?Elimination ends with the row 0 0 0 | 3.
    “0 = 3” is impossible: the system has no solution.

4Eigenvalues and eigenvectors  ★★★

In one minute
What it solves

Finds the special directions a matrix only stretches (never turns), and by how much.

The concept

Av = λv: v is an eigenvector, λ its eigenvalue. Solve det(A − λI) = 0 for λ, then solve (A − λI)v = 0 for each v.

Where it is used

PCA directions, Google PageRank, vibration and stability analysis.

Definition
Av = λv  ⇒  det(A − λI) = 0
The characteristic equation.
Check
λ1 + λ2 = trace(A),   λ1 λ2 = det(A)
A quick check for any 2 × 2 answer.
Worked example — A = [2 1; 1 2]
Find the eigenvalues and eigenvectors.
  1. Characteristic equation(2 − λ)2 − 1 = 0 → λ2 − 4λ + 3 = 0
  2. Eigenvalues(λ − 3)(λ − 1) = 0 → λ = 3, 1
  3. λ = 3(A − 3I)v = 0 → −v1 + v2 = 0 → v = (1, 1)
  4. λ = 1(A − I)v = 0 → v1 + v2 = 0 → v = (1, −1)
  5. Check3 + 1 = 4 = trace ✓; 3 × 1 = 3 = det ✓
λ = 3 with (1, 1); λ = 1 with (1, −1).
Practice
  1. Find: the eigenvalues.A = [4 1; 2 3].
    λ2 − 7λ + 10 = 0 → λ = 5, 2 (sum 7 = trace, product 10 = det).
  2. Answer: what does it mean?A matrix has eigenvalue 0.
    Then det A = 0: the matrix is singular (no inverse).

5Principal Component Analysis (PCA)  ★★★

In one minute
What it solves

Reduces many correlated features to a few new ones that keep most of the information (variance).

The concept

Centre the data, build the covariance matrix, find its eigenvectors (the principal components) and eigenvalues (the variance along each). Keep the components with the largest eigenvalues.

Where it is used

Dimensionality reduction, compression, visualising high-dimensional data, noise removal.

Covariance and its eigenvectors
C = 1n − 1 XcTXc,   Cu = λu
Xc is the data with the mean of each column subtracted.
Variance explained and projection
variance explained by PCi = λiλ1 + λ2 + …;   score z = u·(x − x̄)
Keep components until the total reaches about 90–95 %.
How to solve it in the exam
  1. Subtract the mean from every column (centre the data).
  2. Compute the covariance matrix C.
  3. Find the eigenvalues and eigenvectors of C; sort from largest eigenvalue.
  4. Variance explained = each λ / sum of all λ; choose how many to keep.
  5. Project: z = u·(x − mean) for each kept eigenvector u.
Worked example — PCA on five points
Points (1,1), (2,3), (3,2), (4,5), (5,4).
  1. Mean and centred datamean (3, 3); centred (−2,−2), (−1,0), (0,−1), (1,2), (2,1)
  2. Covariance (divide by 4)var(x) = 10/4 = 2.5, var(y) = 2.5, cov = 8/4 = 2 → C = [2.5 2; 2 2.5]
  3. Eigenvalues(2.5 − λ)2 − 4 = 0 → λ = 4.5, 0.5
  4. PC1u = (1, 1)/√2 = (0.707, 0.707)
  5. Variance explained4.5 / (4.5 + 0.5) = 90 %
  6. Project the first pointz = 0.707(−2) + 0.707(−2) = −2.828
PC1 = (0.707, 0.707) keeps 90 % of the variance; 2-D data can be described by 1 number per point.
Common trap
Always centre (and, if units differ, standardise) before PCA; otherwise the feature with the biggest numbers dominates.
Practice
  1. Find: the share kept.Covariance eigenvalues are 6 and 2.
    PC1 keeps 6 / (6 + 2) = 75 %.
  2. Answer: why centre the data first?Why subtract the mean before PCA?
    PCA looks for directions of spread around the centre; without centring, the first component just points at the mean.

6Linear Discriminant Analysis (LDA)  ★★

In one minute
What it solves

Finds the one direction that best separates two labelled classes, and a threshold to classify new points.

The concept

Project the data on a line w so that the class means are far apart and each class is tight. Fisher's solution: w = SW−1(m1 − m2). Unlike PCA, LDA uses the labels.

Where it is used

Face recognition, medical diagnosis, any two-class problem with numeric features.

Scatter
SW = Σclass 1(x − m1)(x − m1)T + Σclass 2(x − m2)(x − m2)T
Within-class scatter: how spread each class is.
Fisher direction
w = SW−1(m1 − m2),   threshold = midpoint of the projected means
Fisher's criterion: maximise (separation of means)2 / (within-class spread).
Worked example — two classes of three points
Class A: (1,2), (2,1), (3,3). Class B: (6,5), (7,7), (8,6). Classify (4, 4).
  1. MeansmA = (2, 2), mB = (7, 6)
  2. ScatterSA = [2 1; 1 2], SB = [2 1; 1 2] → SW = [4 2; 2 4]
  3. InverseSW−1 = (1/12)[4 −2; −2 4]
  4. Directionw = (1/12)[4 −2; −2 4](−5, −4) = (−1, −0.5), i.e. along (2, 1)
  5. Project the means on (2, 1)A: 2·2 + 2 = 6;  B: 2·7 + 6 = 20 → threshold 13
  6. Classify (4, 4)2·4 + 4 = 12 < 13 → class A
Project on w ∝ (2, 1); threshold 13; (4, 4) belongs to class A.
Practice
  1. Answer: PCA or LDA? Give the reason.You have labelled images of two classes and want the direction that best separates them.
    LDA: it uses the labels and maximises class separation. PCA ignores labels and maximises variance.
  2. Find: which class?Projected means 6 (A) and 20 (B). A new point projects to 15.
    Threshold (6 + 20)/2 = 13; 15 > 13, so class B.

7Image transformations with homogeneous coordinates  ★★★

In one minute
What it solves

Moves, resizes, rotates or shears an image (or shape) using one matrix multiplication per point.

The concept

Write a 2-D point as (x, y, 1). Then translation becomes a matrix too, and several transformations combine into one matrix by multiplying them. The order matters.

Where it is used

Image editing, computer graphics, game engines, augmenting training images.

Basic matrices
T = [1 0 tx; 0 1 ty; 0 0 1],   S = [sx 0 0; 0 sy 0; 0 0 1],   R(θ) = [cosθ −sinθ 0; sinθ cosθ 0; 0 0 1]
Shear: [1 k 0; 0 1 0; 0 0 1]. Reflection in the x-axis: diag(1, −1, 1).
Composition
“first S, then T”  ⇒  M = T · S   (the first one goes on the right)
Matrix order is the reverse of the order you do them.
Worked example — rotation, and why order matters
(i) Rotate (2, 1) by 90° about the origin. (ii) Scale by 2 and translate by (3, 4), in both orders, for the point (1, 1).
  1. R(90°)[0 −1; 1 0] (2, 1) = (−1, 2)
  2. Scale first, then translate (M = T·S)(1, 1) → (2, 2) → (5, 6)
  3. Translate first, then scale (M = S·T)(1, 1) → (4, 5) → (8, 10)
  4. Lessonsame two steps, different order, different result
(−1, 2); (5, 6) vs (8, 10): the order of transformations changes the answer.
Common trap
Without the extra 1 (homogeneous coordinate), translation cannot be written as a matrix product.
Practice
  1. Find: the new point.Rotate (1, 0) by 90°.
    [0 −1; 1 0](1, 0) = (0, 1).
  2. Write: the matrix.Translation by (2, −1) in homogeneous form.
    [1 0 2; 0 1 −1; 0 0 1].

8Image interpolation: nearest neighbour and bilinear  ★★

In one minute
What it solves

Estimates the colour of a pixel that falls between known pixels when an image is resized or rotated.

The concept

Nearest neighbour copies the closest pixel (fast, blocky). Bilinear takes a weighted average of the four surrounding pixels (smoother). Bicubic uses 16 pixels (smoothest, slowest).

Where it is used

Zooming, resizing and rotating images; texture mapping.

Bilinear
f(x, y) = (1−x)(1−y)f00 + x(1−y)f10 + (1−x)y f01 + x y f11
x and y are the fractional distances (0 to 1) inside the cell; the four weights add up to 1.
Worked example — one bilinear value
Corner values f(0,0) = 10, f(1,0) = 20, f(0,1) = 30, f(1,1) = 40. Find the value at (0.25, 0.75).
  1. Weights(0.75)(0.25) = 0.1875; (0.25)(0.25) = 0.0625; (0.75)(0.75) = 0.5625; (0.25)(0.75) = 0.1875
  2. Weighted sum0.1875·10 + 0.0625·20 + 0.5625·30 + 0.1875·40 = 1.875 + 1.25 + 16.875 + 7.5
  3. Bilinear value27.5
  4. Nearest neighbourclosest corner is (0, 1) → 30
Bilinear 27.5; nearest neighbour 30.
Practice
  1. Find: the value.Same corners (10, 20, 30, 40). Bilinear value at the centre (0.5, 0.5)?
    All weights 0.25 → 25, the average.
  2. Answer: which method?Which interpolation makes a zoomed image look blocky?
    Nearest neighbour, because it copies pixels instead of blending them.
